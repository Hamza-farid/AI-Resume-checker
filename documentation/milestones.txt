 ✅ LOGIN + 10-MINUTE SESSION  (frontend/auth.py)
──────────────────────────────────────────────────────────
   What : Login page with 3 fields, JWT token, auto-logout
   .env : APP_USERNAME=...   APP_PASSWORD=...   APP_ACCESS_KEY=...
          JWT_SECRET=...     (long random text, signs the token)
          SESSION_MINUTES=10 (optional, default 10)
   Rules: all 3 must match · one error message for any mistake ·
          5 wrong tries → 60s lock · login not set up → app won't open
   Flow : login → token (exp = now + 10 min) → 🔒 9:59 countdown in
          the header → at 0 the page reloads → login page again
   Logout button clears the form, results and token
   Test : browser test 7/7 ✅ (login page, wrong login, right login,
          evaluate lock, results, auto-logout after 1 min, logout)
