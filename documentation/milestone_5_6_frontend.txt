 3️⃣  ☀️/🌙 THEME SWITCH - how it works
══════════════════════════════════════════════════════════

   The switch is a PLAIN BROWSER BUTTON, not a Streamlit widget.

   1. HR clicks 🌙
   2. session.py already saved form + results (end of every run)
   3. a tiny script stores "Dark" in the browser + reloads
   4. Streamlit opens in dark → session restored → nothing lost

   🐛 Bug we fixed: "card ③ loads late after switching"
      Cause: the old switch was a Streamlit widget → clicking it
             re-ran Python on the OLD page while the reload was
             starting → the run was cut off before card ③ →
             card ③ stayed empty until the new page loaded
      Fix:   plain button → no Python re-run on click
      Proof: 3 switches in a row → 1 run each, uploader shows
             0.01-0.02s after the role box; full page at 0.3s

   Tested in a real browser (Edge):
     background  rgb(246,246,243) → rgb(16,16,16) ✅
     typed role "Data Analyst" still there after the switch ✅

   Note: the uploaded file itself is not kept after a reload
         (browsers don't allow it). The results ARE kept.

 3️⃣➕ BUG FIX: "Evaluate button stays disabled"
══════════════════════════════════════════════════════════

   Cause: a role typed WITHOUT pressing Enter is not sent to
          Python yet → Python thought "no role" → button disabled
   Fix:   button turns on as soon as a file is uploaded;
          the role is checked AFTER the click (the click sends
          the typed role along) → no role = clear warning
   Browser test (real parser + scoring, saved AI answer):
      no file → disabled ✅ · file → enabled ✅ ·
      click without role → warning ✅ · role typed (no Enter)
      + click → results ✅

   ⏱️ Claude Code timeout is now its own setting:
      CLAUDE_CODE_TIMEOUT_SEC = 300 (API stays 180)
